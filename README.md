# Byrect Folders

Direct Folders(Code Sector) 대체를 목표로 한 트레이 상주 즐겨찾기 폴더 메뉴. (v0.4.0)

이전 이름은 DirectFolders. 코드 폴더·프로젝트·네임스페이스 이름은 그대로 두었고, exe·설정 폴더·설치 항목·자동 시작 이름만 바꿨다(`AppInfo.cs`).

## 설치·실행
- 빌드 결과: `publish\ByrectFolders.exe` (단일 exe, 관리자 권한 불필요, .NET 8 Desktop Runtime 필요)
- 설치: exe 실행 → 트레이 아이콘 오른쪽 클릭 → **설치...**
  - `%LOCALAPPDATA%\Programs\ByrectFolders`에 복사, 시작 메뉴 바로가기, Windows 설정 '앱'의 제거 항목 등록
  - 설치 확인 창에서 '예'를 고르면 Windows 시작 시 자동 실행도 등록
  - 설치가 끝나면 설치본이 이어서 실행된다.
- 제거: Windows 설정 > 앱 > Byrect Folders > 제거. 설정(즐겨찾기) 삭제 여부를 묻는다.
- 트레이 아이콘
  - 왼쪽 클릭: 즐겨찾기 메뉴 (선택 시 새 탐색기 창). 더블클릭과 구분하려고 더블클릭 판정 시간(기본 0.5초)만큼 기다린 뒤 뜬다.
  - 더블클릭: 설정 창 열기
  - 오른쪽 클릭: 설정... / 설정 파일 열기 / 설정 다시 읽기 / 최근 폴더 기록 지우기 / Windows 시작 시 실행 / 설치...(설치본이 아닐 때) / 종료
- 처음 실행: Windows 시작 시 자동 실행을 켤지 한 번 묻는다(이미 켜져 있거나 설치 때 답했으면 묻지 않음, `state.json`에 기록). 이어서 Direct Folders 가져오기 안내.
- 이전 이름(DirectFolders)에서 이전: 처음 실행 시 `%APPDATA%\DirectFolders` 내용을 `%APPDATA%\ByrectFolders`로 복사(이전 폴더는 남겨 둠). 자동 시작 등록(Run 값)은 새 이름·현재 exe 경로로 옮기고, 설치 시 이전 설치 폴더·바로가기·제거 항목을 정리한다. 트레이 호스트 창·뮤텍스 이름은 이전 이름을 유지해 이전 빌드와 동시에 실행되지 않는다.

### 명령줄
| 인수 | 동작 |
|---|---|
| (없음) | 트레이 상주 실행(중복 실행 시 바로 종료) |
| `--settings` | 설정 창 열기(실행 중이면 그 인스턴스에서) |
| `--install [--autostart]` | 대화상자 없이 설치 후 설치본 실행 |
| `--uninstall [--quiet]` | 제거(`--quiet`: 확인 없이, 설정 유지) |

### 빌드
```
dotnet publish -c Release -o publish
```

## 메뉴 호출
| 방법 | 동작 범위 |
|---|---|
| 메뉴 단축키 (기본 Ctrl+Alt+D) | 모든 창. 커서 위치에 메뉴 표시(수정자 키를 뗀 뒤 표시) |
| 휠 클릭 | 바탕화면, 탐색기, 열기/저장 대화상자 위에서만. 그 외 창은 원래 동작 그대로 |
| 즐겨찾기별 단축키 | 메뉴 없이 해당 폴더로 바로 이동 |

탐색기·바탕화면에서는 **빈 곳**을 휠 클릭할 때만 메뉴가 뜬다. 파일·폴더·트리·탭 위 휠 클릭은 원래 동작(새 탭으로 열기, 탭 닫기 등)이 그대로 실행된다.

## 메뉴 구성
```
폴더 ▶   열린 탐색기 폴더(가상 폴더 제외, 최대 20개) / 최근 폴더(이 프로그램으로 이동한 폴더, 최대 15개)
파일 ▶   Windows 최근 파일(최대 20개, 오른쪽에 위치 표시)
───────
즐겨찾기 (그룹은 하위 메뉴, 단축키가 있으면 오른쪽에 표시)
───────
여기 추가...   호출한 창의 현재 폴더를 즐겨찾기 끝에 추가(이름 입력). 오른쪽에 대상 폴더 이름 표시
───────
설정...   설정 창 열기(톱니바퀴 아이콘)
```
- 설정 파일 열기 / 설정 다시 읽기 / 최근 폴더 기록 지우기는 트레이 아이콘 오른쪽 클릭 메뉴에 있다.
- 항목마다 아이콘 표시(폴더, 파일 형식별 셸 아이콘).
- 최근 파일 선택: 대화상자면 그 파일이 있는 폴더로 이동하고 파일 이름 칸에 이름을 넣는다(확인은 누르지 않음). 그 외에는 기본 앱으로 연다.
- 여기 추가 대상: 탐색기는 활성 탭 폴더, 대화상자는 주소 표시줄 폴더, 바탕화면은 바탕 화면 폴더. 그 외 창에서는 비활성.
  추가하면 설정 파일을 새로 저장하므로 직접 써 둔 주석은 사라진다(`.bak` 보관). 열려 있던 설정 창은 닫힌다.
- 최근 폴더 기록: `%APPDATA%\ByrectFolders\history.json`

## 폴더 선택(또는 즐겨찾기 단축키) 시 동작
| 대상 창 | 동작 |
|---|---|
| 열기/저장 대화상자 | 대화상자를 해당 폴더로 이동. 파일 이름 칸 내용 유지 |
| 탐색기 창 | 그 창의 활성 탭에서 바로 이동. 새 창·새 탭을 만들지 않음 |
| 그 외(바탕화면, 일반 앱, 트레이) | 새 탐색기 창으로 열기 |

대상 창은 메뉴는 호출한 창, 즐겨찾기 단축키는 누를 때 활성 창. 이동에 실패하면 새 탐색기 창으로 연다.

## Direct Folders에서 가져오기
Code Sector Direct Folders의 설정을 읽어 즐겨찾기와 최근 폴더를 가져온다.
- 원본: `%APPDATA%\Direct Folders\menu.json`(즐겨찾기), 같은 폴더의 `folders.txt`(최근 폴더). 없으면 `%LOCALAPPDATA%`, Program Files 아래 `Direct Folders`도 찾는다.
- 처음 실행 시 원본이 있고 새로 가져올 항목이 있으면 가져올지 묻는다. 예/아니요와 상관없이 한 번만 묻는다(`state.json`에 기록). 원본이 없으면 기록하지 않고 다음 실행 때 다시 확인한다.
- 설정 > 즐겨찾기 탭 > "Direct Folders에서 가져오기": 원본을 못 찾으면 menu.json을 직접 고른다. 목록 끝에 추가되며 저장해야 반영된다.
- 이미 등록된 경로(대소문자·끝 `\` 무시)는 건너뛴다. 즐겨찾기는 기존 목록 끝에 구분선 뒤로 추가, 최근 폴더는 기존 기록 뒤에 최대 20개까지 덧붙인다.
- 단축키(Direct Folders 메뉴 단축키 등)와 파일 항목은 가져오지 않는다.

## 앱별 기본 폴더
특정 앱에서 열기/저장 대화상자가 뜨면 지정 폴더로 자동 이동한다(파일 이름 칸 유지).
- 규칙: 앱(exe 이름), 대화상자 종류(모두/열기/저장), 제목 포함 문자열(선택), 폴더.
- 위에서부터 처음 맞는 규칙 하나만 적용. 같은 대화상자는 한 번만 이동하므로, 뜬 뒤 사용자가 옮긴 폴더는 되돌리지 않는다.
- 앱이 자체 초기 폴더로 이동을 마치도록 약 0.25초 뒤에 이동한다.
- 폴더가 없으면 이동하지 않고 로그에 남긴다.
- 설정 창의 "앱별 기본 폴더" 탭에서 추가/편집/삭제/순서 변경. 앱 칸은 실행 중인 앱 목록에서 고를 수 있다.

## 설정 창 (트레이 > 설정... 또는 메뉴 > 설정...)
탭: 즐겨찾기 / 앱별 기본 폴더 / 일반.
- 즐겨찾기 탭: 왼쪽 타일 = 도구 모음(폴더 추가, 열린 탐색기에서 ▾, 그룹, 구분선, ▲▼) + 목록. 오른쪽 타일 "선택한 항목" = 이름·경로(찾아보기)·단축키 + "이 항목 삭제".
- 일반 탭: 메뉴 단축키, 휠 클릭 사용, 열린 탐색기 폴더 표시, Direct Folders에서 가져오기.
- 실행 취소: Ctrl+Z, 다시 실행: Ctrl+Y(또는 Ctrl+Shift+Z). 변경이 끝날 때마다 창 전체 상태(즐겨찾기·앱별 규칙·일반 설정)를 스냅숏으로 남기는 방식(최대 200단계). 같은 칸에 이어서 입력한 글자는 한 단계로 묶인다. 단축키 입력 칸에서는 가로채지 않는다.
- 그룹 버튼: 여러 항목을 선택한 상태면 그 항목들을 새 그룹으로 묶고, 아니면 빈 그룹을 추가한다.
- 저장: '저장' 버튼은 저장만 하고 창은 닫지 않는다. Enter로는 저장되지 않는다(기본 버튼 미지정). '닫기'·Esc·X로 닫으며, 저장하지 않은 변경이 있으면 저장할지 묻는다.
- 목록에서 바로 이름 바꾸기: F2, 선택된 항목 이름을 한 번 더 클릭, 우클릭 > 이름 바꾸기. 새 그룹은 만들자마자 이름 입력 상태가 된다(Enter 확정, Esc 취소).
- 선택된(파랗게 표시된) 행은 이름 위가 아니어도 어디를 잡아 끌어도 이동된다. 선택되지 않은 행의 빈 곳에서 끌면 러버밴드 선택.
- 왼쪽 아래 "? 도움말": 현재 탭의 사용법을 팝업으로 표시(내용은 `SettingsForm.cs`의 FavoritesHelp/AppHelp/GeneralHelp).
- 테마(일반 탭 > 화면 > 테마, 설정 파일의 `theme`): Aplaybox Downloader의 테마를 옮긴 것. 저장하면 설정 창이 새 테마로 다시 열린다.
  - `aero`(기본): Frutiger Aero. 하늘색 그라데이션 바탕, 흰 유리 패널(옅은 파란 고리 + 그림자), 남색 글자, 파란 그라데이션 기본 버튼, 제목 앞 아쿠아→민트 강조 막대.
  - `light`: Bento. 회색 바탕 위 흰 둥근 타일, 파란 강조색(#1a7cff). 이전 기본 테마를 그대로 보존.
  - 색·모양 값은 `Theme.cs`의 `Palette`(Light / Aero) 두 벌. 규칙 편집·즐겨찾기 추가·도움말 대화상자와 팝업 메뉴(둥근 모서리)도 같은 테마를 쓴다.
  - 창 바탕 위 컨테이너는 `CanvasPanel`/`CanvasTable`이 자기 자리의 바탕을 직접 그린다(투명 BackColor 방식은 부분 다시 그리기 때 그라데이션이 어긋나 쓰지 않음).
- 글꼴: 나눔스퀘어라운드 Bold를 exe에 내장(설치 불필요, 없으면 맑은 고딕). SIL OFL 1.1, 고지문은 exe 옆 `Assets\NOTICE-NanumSquareRound.txt`.
설정 관련 창은 시스템 DPI 인식으로 만든다. 배율이 다른 모니터가 섞인 환경에서 WinForms의 모니터별 배율이 일부 컨트롤에만 적용돼 글자가 잘리던 문제 대응. 주 배율(150%)과 다른 모니터에서는 Windows가 확대/축소해 그리므로 약간 흐릴 수 있다.

- 목록: 끌어서 순서 변경, 그룹 위에 놓으면 그룹 안으로 이동. 여러 개 선택한 상태에서 선택 항목을 끌면 함께 이동.
- 다중 선택: 빈 곳(항목 이름 오른쪽 여백 포함)에서 끌면 러버밴드(사각형) 선택, Ctrl+클릭 추가/해제, Shift+클릭 범위, Ctrl+A 전체. Ctrl을 누른 채 끌면 기존 선택에 더한다. 끌다가 목록 위·아래로 벗어나면 자동 스크롤.
- 우클릭 메뉴
  - 항목 하나: 이름 바꾸기(F2), 경로 바꾸기, 단축키 지정, 그룹 풀기(그룹), 그룹으로 묶기, 그룹으로 이동 ▶, 삭제(Del)
  - 여러 개: 그룹으로 묶기, 그룹으로 이동 ▶, 경로 일괄 바꾸기(드라이브·상위 폴더 변경용, 공통 경로를 미리 채움), 삭제
  - 빈 곳: 폴더 추가, 그룹 추가, 구분선 추가
  - 그룹으로 묶기: 첫 항목 자리에 "새 그룹"을 만들고 목록에서 바로 이름 입력 상태가 된다. 여러 개 삭제는 확인 후 진행.
- 단축키 칸은 클릭 후 조합키를 누르면 입력되고, Backspace로 지운다.
- 저장 시 단축키 형식·중복(메뉴 단축키 포함)을 검사한다. 저장하면 `favorites.json`을 새로 쓰고 이전 파일은 `favorites.json.bak`으로 보관한다. 이때 직접 써 둔 주석은 사라진다.

## 설정 파일
위치: `%APPDATA%\ByrectFolders\favorites.json`. 직접 편집해도 된다(주석 `//`, 끝 쉼표 허용). 수정 후 트레이 > 설정 다시 읽기.

```jsonc
{
  "hotkey": "Ctrl+Alt+D",     // 메뉴 단축키. Ctrl, Alt, Shift, Win + 키(A~Z, 0~9, F1~F24 등)
  "middleClick": true,
  "showOpenFolders": true,
  "theme": "aero",              // 설정 창 테마: aero(기본) / light
  "items": [
    { "name": "다운로드", "path": "%USERPROFILE%\\Downloads", "hotkey": "Ctrl+Alt+1" },
    { "separator": true },
    { "name": "작업", "items": [ { "name": "D:\\work", "path": "D:\\work" } ] }
  ],
  "appFolders": [
    // dialog: both(생략 시) / open / save, title: 대화상자 제목에 포함될 문자열(선택)
    { "app": "3dsmax.exe", "dialog": "open", "title": "Import", "path": "D:\\work\\import" },
    { "app": "Photoshop.exe", "dialog": "save", "path": "D:\\work\\export" }
  ]
}
```
- 존재하지 않는 경로는 메뉴에서 회색 비활성 표시.
- 단축키 등록 실패(다른 프로그램이 사용 중 등)나 형식 오류는 트레이 알림으로 표시.

## 로그
`%APPDATA%\ByrectFolders\log.txt` — 메뉴 대상 창, 항목/빈 곳 판별, 열린 폴더 조회 시간, 대화상자·탐색기 이동, 설치·제거 기록(512KB 초과 시 초기화).

## 구현 메모
- 휠 클릭 훅(WH_MOUSE_LL)은 전용 스레드에서 돈다. UI 스레드가 막혀도 Windows가 훅을 건너뛰거나 해제하지 않게 하기 위함.
- 탐색기·바탕화면 휠 클릭: 일단 가로챈 뒤 UI Automation으로 클릭 위치를 판별. 항목 위면 표식을 붙여 같은 클릭을 다시 보내고(훅은 표식이 있으면 통과), 빈 곳이면 메뉴.
- 대화상자 이동: 파일 이름 칸 보관 → 폴더 경로 입력 → 확인 → 이동 확인 후 복원. 파일 이름 칸 판별 순서: ID 1148 > `FloatNotifySink > ComboBox > Edit(1001)` > ID 1152.
- 탐색기 이동: ShellWindows에서 HWND가 같고 활성 탭(첫 번째 `ShellTabWindowClass`)인 항목에 `Navigate2`.

## 한계
- Qt 등으로 자체 대화상자를 그리는 앱은 판별되지 않아 탐색기로 열린다.
- 관리자 권한으로 실행된 앱의 창은 조작할 수 없다(UIPI). 새 탐색기 창으로 대체.
- 탐색기 항목 위 휠 클릭은 판별 시간만큼(약 0.1초) 늦게 원래 동작이 실행된다. 휠 버튼을 누른 채 끄는 동작은 재현하지 않는다.
- 설정 창 저장 시 설정 파일의 주석이 사라진다(`.bak`에 보관).
